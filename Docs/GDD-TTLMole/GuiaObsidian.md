##  Guia Rápido de Uso do Obsidian / GitHub
*Esta seção é para quem não está familiarizado com o Obsidian. O Obsidian usa uma linguagem de formatação chamada **Markdown**.*

### 1. Títulos e Formatação
*   `# Título Principal`, `## Subtítulo`, `### Tópico`
*   **Negrito:** `**Texto em negrito**` ➔ **Texto em negrito**
*   ==Destacar:== `==Texto destacado==` ➔ ==Texto destacado==
*   **Caixa de tarefas:** `- [ ] Tarefa pendente` ➔ Cria um checklist.

### 2. Links e Imagens
*   **Link interno:** `[[Nome da Página]]`.
*   **Adicionar Imagem:** Arraste a imagem para dentro do Obsidian. O código será `![[nome_da_imagem.png]]`.
